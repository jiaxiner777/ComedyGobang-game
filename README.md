# 🎭 喜剧五子棋 (Comedy Gobang)

将经典小品梗与传统五子棋结合，打造一款"一本正经胡说八道"的竞技小游戏。

## 🎮 游戏特色

### 核心玩法
- **15x15标准棋盘**：传统五子棋规则
- **技能系统**：积攒能量释放戏剧性技能
- **实时对战**：支持双人对战

### 🃏 三大喜剧技能

#### 1. 贾总的咆哮 📢
- **效果**：强行移除对方棋盘上任意一颗棋子
- **视觉反馈**：屏幕剧烈抖动，弹出巨大文字"尴尬不？"
- **能量消耗**：30点
- **冷却时间**：3回合

#### 2. 淡定一坐 🪑
- **效果**：禁手一轮，对方下回合无法落子
- **视觉反馈**：播放"搬椅子坐下"音效，对方棋盘变灰
- **能量消耗**：40点
- **冷却时间**：4回合

#### 3. 神级反转 🔄
- **效果**：随机选取棋盘上黑白各两颗棋子交换位置
- **视觉反馈**：屏幕闪现"这就是命！"，棋子位移动画
- **能量消耗**：50点
- **冷却时间**：5回合

### 💬 弹幕语录系统
游戏过程中会实时显示喜剧语录：
- 普通落子："嘿，这棋下的，很有画面感啊！"
- 围堵成功："你这是把我往死里整啊，兄弟。"
- 长考提醒："逻辑！注意你的逻辑！"
- 技能释放："厉害！这波操作我给满分！"

### 🎨 复古小品舞台UI
- **深红色大幕布**背景纹理
- **金光闪烁**技能可用提示
- **动态弹幕**滚动显示

## 🚀 快速开始

### 编译运行
```bash
# 克隆项目
git clone <repository-url>
cd ComedyGobang-game

# 安装依赖
go mod tidy

# 编译
go build -o comedy-gobang.exe

# 运行
./comedy-gobang.exe
```

### 访问游戏
打开浏览器访问：http://localhost:8080

## 🏗️ 技术架构

### 后端 (Go)
- **Gin框架**：HTTP服务器
- **WebSocket**：实时通信
- **go:embed**：前端文件嵌入
- **核心模块**：
  - `Room Manager`：房间管理
  - `Game Logic`：游戏逻辑判定
  - `Quote Engine`：语录引擎

### 前端 (Vue.js + Canvas)
- **Vue.js 3**：UI状态管理
- **Canvas**：棋盘渲染和动画
- **TailwindCSS**：样式框架
- **WebSocket Client**：实时通信

## 🎯 游戏玩法

1. **创建/加入房间**
   - 输入玩家名称
   - 创建新房间或加入现有房间

2. **准备开始**
   - 双方玩家点击"准备游戏"
   - 系统随机决定先手

3. **落子对战**
   - 点击棋盘格子落子
   - 每次落子获得5点能量
   - 回合开始获得3点能量

4. **释放技能**
   - 能量足够时点击技能按钮
   - 部分技能需要选择目标位置
   - 注意技能冷却时间

5. **获得胜利**
   - 率先连成五子获胜
   - 享受胜利语录和动画
